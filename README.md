# AeroSense AI
## Smart City Air Quality Forecasting & Health Advisory System

An AI-powered mini project that forecasts Air Quality Index (AQI) using historical data and provides health advisories through an interactive Streamlit dashboard.

### Features
- Interactive Streamlit dashboard
- Machine learning-based AQI forecasting
- Historical AQI visualization
- AQI-based health advisories

### Technologies
Python, Streamlit, Pandas, NumPy, Scikit-learn, and visualization libraries used by the application.
